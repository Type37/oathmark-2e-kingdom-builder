# Name pools

The 🎲 roll buttons draw from these lists (`src/names.mjs`). Each roll picks at random and never repeats the current value.

| Pool | Used for | Entries | Source |
|---|---|---|---|
| Realm names | Kingdom Name | 30 | Written for this app on 2026-09-22 by Claude, modelled on the book's example kingdoms, Grundeland and Vasala (p24). Not from any published source. |
| Army names | Army Name | 30 | `WARBAND_NAMES` in the Dragon Rampant 2e builder (`Dragon-Rampant-Builder2e/src/factions.js`), committed 2026-07-08. Hand-written generic fantasy warband names; the file cites no published source. The Rottingutt and Foul-Wind entries nod to the Dragon Rampant rulebook's sample warband. |
| Hero names | Current Ruler, Army Commander | 25 | `HERO_NAMES` from the same Dragon Rampant file, with the same provenance. |

The sci-fi pools you remembered (Infinity and others) are in the Xenos Rampant builder, `Xenos Rampant/src/factions.js`. They are not used here.
